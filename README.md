# سند — روبوت محادثة ذكي لأتمتة الطلبات الروتينية

نموذج أولي (Prototype) لمساعد رقمي يعتمد على الذكاء الاصطناعي للرد الفوري وإنجاز الطلبات المتكررة على مدار الساعة.

هذا مشروع **ثابت (Static)** — ملف HTML واحد بدون أي إعداد بناء (build)، جاهز للنشر مباشرة. محادثة الشات في الصفحة الرئيسية عبارة عن **محاكاة تفاعلية (Mock)** لأغراض العرض، وليست متصلة بذكاء اصطناعي حقيقي.

## التشغيل محلياً
افتح `index.html` في أي متصفح.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد إليه.
2. من إعدادات المستودع: **Settings → Pages**.
3. تحت **Build and deployment**، اختر **Source: Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/ (root)`، ثم احفظ.
5. بعد دقيقة تقريباً سيكون الموقع متاحاً على:
   `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

## هيكل الملفات
```
sanad/
├── index.html      ← الصفحة الكاملة (HTML + CSS + JS مضمّنة)
└── assets/
    └── logo.png    ← شعار جامعة الطائف
```

## ربط ذكاء اصطناعي حقيقي لاحقاً
محادثة العرض التوضيحي مكتوبة كخطوات ثابتة داخل `index.html` (دالة `playSteps`). لربطها بنموذج حقيقي، استبدل هذه الدالة باستدعاء API فعلي (مثل Claude عبر endpoint خلفي) يستقبل رسالة المستخدم ويعيد الرد.
